Onde estou e o que tem aqui

Os comandos de orientação. Use-os o tempo todo: quem está perdido no terminal quase sempre resolve com pwd e ls.

  • pwd
    mostra em qual pasta você estáVem de Print Working Directory. A resposta é o caminho completo, como /home/voce/padaria. No PowerShell também funciona.
    treino
  • ls
    lista os arquivos e pastas daquiPastas aparecem com uma barra no fim. No Prompt de Comando do Windows o equivalente é dir.
    treino
  • ls -la
    lista tudo, com detalhes e arquivos ocultos-l mostra tamanho, data e permissões; -a inclui os ocultos, que começam com ponto (.gitignore, por exemplo). No treino existe só o ls simples.
  • cd pasta
    entra na pastacd padaria entra na pasta padaria. Dica de verdade: digite as primeiras letras e aperte Tab para completar o nome.
    treino
  • cd ..
    volta uma pastaOs dois pontos significam a pasta de cima. cd ../.. volta duas.
    treino
  • cd
    vai para a sua pasta pessoalNo Mac e no Linux, cd ~ faz o mesmo. No Windows PowerShell, cd ~ também funciona.
    treino
  • cd -
    volta para a pasta onde você estava antesFunciona no Mac, no Linux e no Git Bash. Útil para alternar entre duas pastas.
  • tree
    desenha a árvore de pastas e arquivosNo Windows já vem instalado. No Mac e no Linux, pode precisar instalar. Bom para ver a estrutura de um projeto inteiro.
6 comandos

Criar pastas e arquivos

Quase todo projeto começa por aqui: uma pasta, um index.html, uma pasta de imagens.

  • mkdir nome
    cria uma pastamkdir imagens cria a pasta imagens. No Windows o atalho é md.
    treino
  • mkdir -p a/b/c
    cria várias pastas aninhadas de uma vezSem o -p o comando falha se a pasta do meio ainda não existir.
  • touch arquivo
    cria um arquivo vazioSe o arquivo já existe, só atualiza a data de modificação. No PowerShell use ni arquivo (New-Item).
    treino
  • echo 'texto' > arquivo
    escreve o texto no arquivo, apagando o que haviaO sinal > redireciona o que o echo diria na tela para dentro do arquivo. Se o arquivo não existe, ele é criado.
    treino
  • echo 'texto' >> arquivo
    acrescenta o texto no fim do arquivoO >> não apaga nada: só adiciona uma linha nova ao final. É assim que o treino monta o HTML e o CSS aos poucos.
    treino
  • code .
    abre a pasta atual no VS CodeO ponto é a pasta atual. code arquivo.html abre só aquele arquivo. Precisa do VS Code instalado com o comando code ativado.
    treino
7 comandos

Ver o conteúdo

Para ler arquivos sem abrir um editor.

  • cat arquivo
    mostra o conteúdo inteiro do arquivoNo Windows (Prompt de Comando) o equivalente é type arquivo. Em arquivos muito grandes, prefira o less.
    treino
  • head -n 5 arquivo
    mostra só as 5 primeiras linhasTroque o 5 pelo número que quiser. No PowerShell: Get-Content arquivo -TotalCount 5.
  • tail -n 5 arquivo
    mostra só as 5 últimas linhastail -f arquivo fica acompanhando o fim do arquivo em tempo real, ótimo para ler registros (logs) de um servidor. Ctrl + C sai.
  • less arquivo
    abre o arquivo página por páginaSetas e espaço navegam, / procura um texto e q sai. Não existe no Prompt de Comando do Windows; use more arquivo.
  • grep palavra arquivo
    mostra as linhas que contêm a palavra-i ignora maiúsculas, -n mostra o número da linha, -r procura dentro de todas as pastas. No Windows: findstr palavra arquivo.
  • wc -l arquivo
    conta quantas linhas o arquivo temwc vem de word count. -w conta palavras e -c conta bytes.
  • clear
    limpa a tela do terminalNo Windows (Prompt de Comando): cls. O atalho Ctrl + L também limpa na maioria dos terminais.
    treino
2 comandos

Copiar, mover e renomear

Mover e renomear são o mesmo comando: mudar o nome é mudar o caminho.

  • cp origem destino
    copia um arquivocp index.html copia.html faz uma cópia. Para copiar uma pasta inteira, use cp -r pasta nova. No Windows: copy.
  • mv origem destino
    move ou renomeiamv index.html inicio.html renomeia; mv foto.png imagens/ move para a pasta imagens. No Windows: move (mover) e ren (renomear).

Apagar (sem lixeira!)

No terminal não existe lixeira. O que é apagado, some. Confira o nome duas vezes antes de apertar Enter.

  • rm arquivo
    apaga um arquivo para semprerm -i arquivo pergunta antes de apagar. No Windows: del arquivo.
    treino
  • rm -r pasta
    apaga a pasta e tudo que está dentro-r quer dizer recursivo. Cuidado redobrado: um erro de digitação pode apagar o projeto inteiro. No Windows: rmdir /s pasta.
    treino
  • rmdir pasta
    apaga só pasta vaziaMais seguro que o rm -r: se a pasta tiver algo dentro, o comando se recusa.
3 comandos

Buscar

Quando você sabe que o arquivo ou o texto existe, mas não lembra onde.

  • find . -name "*.html"
    acha arquivos pelo nome, a partir da pasta atualO ponto é a pasta atual e o * vale por qualquer sequência de letras. No PowerShell: Get-ChildItem -Recurse -Filter *.html.
  • grep -r "texto" .
    procura um texto dentro de todos os arquivos da pastaÓtimo para achar onde uma cor, um título ou uma função foi usada em um projeto.
  • which node
    mostra onde um programa está instaladoSe não aparecer nada, o programa não está instalado ou não está no PATH. No Windows: where node.

Ferramentas do dia a dia

Programas que você instala uma vez e usa em todo projeto. Para conferir se estão instalados, peça a versão.

  • node -v
    mostra a versão do Node.js, se estiver instaladoSe aparecer "comando não encontrado", falta instalar (nodejs.org).
    treino
  • npm -v
    mostra a versão do npm, o gerenciador de pacotes do NodeO npm baixa bibliotecas prontas para o seu projeto.
    treino
  • git --version
    mostra a versão do Git, se estiver instaladoVeja a seção de Git mais abaixo.
    treino
  • npm init -y
    cria o arquivo package.json do projetoO package.json guarda o nome do projeto e a lista de bibliotecas que ele usa.
  • npm install pacote
    baixa uma biblioteca para o projetoCria a pasta node_modules. Não copie essa pasta para o GitHub: o .gitignore existe para isso.
  • npx serve
    abre um servidor local para a pasta atualDepois abra o endereço mostrado (geralmente http://localhost:3000). Útil para testar o site como se estivesse no ar.
  • python -m http.server 8000
    outro jeito de abrir um servidor localSe você tem Python, abre http://localhost:8000 com os arquivos da pasta. Ctrl + C encerra.

Git: o caderno de versões

O Git guarda o histórico do projeto. Os comandos abaixo são os do dia a dia, na ordem em que costumam aparecer. Você usa os principais na aula 10.

  • git init
    transforma a pasta em um repositório GitCria uma pasta oculta .git, onde o histórico fica guardado. Rode uma vez por projeto. Aula 10.
    aula 10
  • git status
    mostra o que mudou desde o último commitArquivos novos, alterados e prontos para commit aparecem em listas separadas. É o comando mais usado do Git. Aula 10.
    aula 10
  • git add .
    prepara todas as mudanças para o próximo commitO ponto é a pasta atual. git add arquivo prepara só aquele. Aula 10.
    aula 10
  • git commit -m "mensagem"
    salva uma versão no históricoA mensagem diz o que mudou, escrita para quem for ler depois (inclusive você). Aula 10.
    aula 10
  • git log --oneline
    lista os commits, um por linhaMostra o código curto de cada versão e a mensagem. q sai. Aula 10.
    aula 10
  • git diff
    mostra, linha a linha, o que mudouLinhas com - foram removidas e linhas com + foram adicionadas.
  • git switch -c nome
    cria e muda para uma ramificação nova (branch)Ramificações deixam você testar uma ideia sem mexer na versão principal. Em versões antigas: git checkout -b nome.
  • git remote add origin URL
    liga a pasta a um repositório do GitHuborigin é o apelido do endereço remoto. Aula 10.
    aula 10
  • git push -u origin main
    envia o histórico para o GitHubO -u lembra o destino, então das próximas vezes basta git push. Aula 10.
    aula 10
  • git pull
    baixa e junta o que mudou no GitHubUse antes de começar a trabalhar quando mais de uma pessoa mexe no projeto.
  • git clone URL
    baixa uma cópia de um repositórioCria uma pasta nova com todo o histórico do projeto.

Internet e servidores

Para conversar com servidores e conferir endereços, sem navegador.

  • curl endereço
    faz um pedido (GET) e mostra a respostacurl /api/itens pede a lista de itens ao servidor de treino. Aula 8.
    aula 8
  • curl -X POST endereço -d '{...}'
    envia dados ao servidor (POST)-X escolhe o método e -d leva o corpo, em JSON. Aula 8.
    aula 8
  • curl -H "Authorization: Bearer $TOKEN" endereço
    envia um cabeçalho, como o token de acesso-H adiciona um cabeçalho ao pedido. É assim que a API sabe quem você é. Aula 9.
    aula 9
  • curl -I endereço
    mostra só os cabeçalhos da respostaRápido para conferir se o site está no ar (200) ou não (404). Aula 10.
    aula 10
  • ping dominio.com
    testa se o servidor responde e quanto demoraCtrl + C encerra. No Windows manda 4 pacotes e para sozinho.
  • nslookup dominio.com
    consulta o DNS: para onde o nome apontaMostra o endereço IP ou o CNAME. Útil depois de configurar um domínio próprio. Aula 10.
    aula 10
  • ipconfig
    mostra o endereço IP do seu computador (Windows)No Mac: ifconfig. No Linux: ip a.
  • ssh usuario@servidor
    entra em outro computador pela redeÉ assim que se administra um servidor de verdade. Pede senha ou chave.

Atalhos de teclado do terminal

Os atalhos que mais economizam tempo. Quase todos funcionam em qualquer terminal.

  • Seta ↑ e ↓
    percorre os comandos que você já digitouEvita redigitar. No treino também funciona.
    treino
  • Tab
    completa o nome do arquivo ou da pastaAperte duas vezes para ver todas as opções possíveis.
  • Ctrl + C
    interrompe o comando que está rodandoÉ a saída de emergência quando algo trava ou fica rodando para sempre.
  • Ctrl + L
    limpa a telaIgual ao comando clear.
  • Ctrl + R
    busca no histórico de comandosDigite um pedaço do comando antigo e ele aparece. No PowerShell use a seta ↑ com o início do comando.
  • Ctrl + A · Ctrl + E
    vai para o começo · fim da linhaMuito útil para corrigir um comando longo. No Windows, as teclas Home e End fazem o mesmo.
  • history
    lista os comandos que você já usouCada um tem um número; !42 repete o de número 42 no Mac e no Linux.
  • exit
    fecha o terminalOu feche a janela. Em conexões ssh, volta para o seu computador.

Programas rodando

Quando um programa fica preso ou você precisa saber o que está aberto.

  • ps
    lista os programas rodando no terminalps aux mostra todos os programas do computador (Mac e Linux). No Windows: tasklist.
  • kill número
    encerra um programa pelo número deleO número (PID) vem do ps. No Windows: taskkill /PID número. Só use se o Ctrl + C não resolver.
  • chmod +x script.sh
    torna um arquivo executávelNo Mac e no Linux, um script só roda como programa depois disso: ./script.sh. O Windows não usa permissões desse jeito.
Quando algo dá errado

Mensagens de erro comuns.

Erro no terminal não é falha sua: é o computador explicando o que não conseguiu fazer. Leia a primeira linha com calma.

  • command not found · não é reconhecido como um comandoO programa não está instalado, ou o nome foi digitado errado. Confira com which nome (Windows: where nome) e reveja a ortografia.
  • No such file or directory · não pode encontrar o caminhoO arquivo ou a pasta não existe daquele jeito. Use pwd para saber onde está, ls para ver o que tem aqui e confira maiúsculas e minúsculas.
  • Permission denied · acesso negadoVocê não tem permissão para fazer isso naquele lugar. Confira se está na pasta certa; nunca use sudo sem entender o comando.
  • fatal: not a git repositoryA pasta ainda não é um repositório Git. Entre na pasta certa (cd) e rode git init, ou clone um repositório.
  • Is a directory · Not a directoryVocê usou como arquivo algo que é pasta (ou o contrário). O ls mostra pastas com uma barra no fim.
  • Aspas ou chaves sem fecharO terminal espera você terminar o texto. Aperte Ctrl + C e digite de novo, fechando todas as aspas.
