1 · O terminal

Falar com o computador por texto.

O terminal é uma janela em que, em vez de clicar em pastas e botões, você digita instruções curtas chamadas comandos. Quem faz sites usa o terminal o tempo todo porque é rápido, repetível e funciona igual em qualquer computador. Não tem nada de mágico: cada comando faz uma coisa pequena.

Qual terminal abrir?

  1. Aperte a tecla Windows do teclado.

  2. Digite Terminal (ou PowerShell) e aperte Enter. Abre uma janela escura com um texto piscando: é ele.

  3. Dica: para abrir já dentro de uma pasta, abra a pasta no Explorador de Arquivos, clique na barra de endereço no topo, digite powershell e aperte Enter.

  2. Digite Terminal e aperte Enter.

  3. Dica: no Finder, clique com o botão direito numa pasta e escolha Novo Terminal na Pasta (ative em Ajustes, Teclado, Atalhos, Serviços).

  2. Se não abrir, procure por Terminal no menu de aplicativos.

  3. Dica: no gerenciador de arquivos, clique com o botão direito dentro de uma pasta e escolha Abrir no terminal.

2 · Os aplicativos

O que instalar (e o que você já tem).

Você já temNavegador

Chrome, Edge, Firefox ou Safari. É nele que você vê o resultado do seu site.

Já vem no sistemaTerminal

Você acabou de aprender a abrir. Não precisa instalar nada.

Instale agoraEditor de código

O VS Code (code.visualstudio.com) é gratuito e o mais usado. É o caderno em que você escreve o HTML.

Instale depoisGit e Node.js

O Git guarda versões do projeto; o Node.js roda JavaScript fora do navegador. Entram nas aulas de JavaScript e publicar.

Para conferir se um programa está instalado, o terminal responde com a versão: node -v ou git --version. Se aparecer "comando não encontrado", falta instalar.

3 · Os comandos

A cola que cabe em uma tela.

Você não precisa decorar. Treine logo abaixo e deixe esta lista aberta ao lado.

Onde estou e o que tem aqui

  • pwdmostra em qual pasta você está
  • lslista os arquivos e pastas daqui (no Windows: dir)
  • cd pastaentra na pasta · cd .. volta uma · cd sozinho vai para a sua pasta pessoal

Criar

  • mkdir nomecria uma pasta (no Windows: md nome)
  • touch arquivocria um arquivo vazio (no Windows PowerShell: ni arquivo)
  • echo 'texto' > arquivoescreve o texto no arquivo, apagando o que havia
  • echo 'texto' >> arquivoacrescenta o texto no fim do arquivo

Ver

  • cat arquivomostra o conteúdo do arquivo (no Windows: type arquivo)
  • clearlimpa a tela do terminal (no Windows: cls)

Apagar (sem lixeira!)

  • rm arquivoapaga um arquivo para sempre
  • rm -r pastaapaga a pasta e tudo que está dentro. Cuidado

Ferramentas

  • code .abre a pasta atual no editor VS Code
  • node -vmostra a versão do Node.js, se estiver instalado
  • git --versionmostra a versão do Git, se estiver instalado
