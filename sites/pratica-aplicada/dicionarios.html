Estrutura da página

O esqueleto que toda página tem. Escreva uma vez e reaproveite.

  • <!doctype html>
    avisa o navegador de que a página é HTML modernoVai na primeira linha. Sem ele o navegador entra em modo antigo.
  • <html lang="pt-BR">
    envolve a página inteira e diz o idiomaO lang ajuda leitores de tela e tradutores.
  • <head>
    guarda o que não aparece na tela: título, estilos e configuraçõesFica antes do body.
  • <body>
    guarda tudo o que aparece na telaTextos, imagens, botões e links.
  • <title>
    o nome da página, mostrado na aba do navegadorTambém é o título que aparece nas buscas.
  • <meta charset="utf-8">
    faz acentos e símbolos aparecerem certosColoque dentro do head.
  • <meta name="viewport" content="width=device-width, initial-scale=1">
    faz a página caber na tela do celularSem ele o celular encolhe tudo.
  • <link rel="stylesheet" href="estilo.css">
    liga um arquivo de CSS à páginaVai dentro do head.
  • <script src="script.js"></script>
    liga um arquivo de JavaScriptColoque no fim do body, para o HTML já existir quando o código rodar.
  • <!-- recado -->
    um comentário que o navegador ignoraBom para lembrar o que cada bloco faz.

Texto

Títulos, parágrafos e destaques.

  • <h1> … <h6>
    títulos, do maior ao menorUse um h1 por página; os outros organizam as seções.
  • <p>

  • <br>
    quebra de linha dentro do textoNão precisa fechar.
  • <hr>
    uma linha horizontal separando partesTambém não precisa fechar.
  • <strong>
    texto importante, em negritoLeitores de tela dão ênfase.
  • <em>
    texto com ênfase, em itálicoUse para destacar uma palavra na frase.
  • <span>
    um pedaço de texto sem significado próprioServe para aplicar estilo a um trecho: <span class="destaque">.
  • <blockquote>
    uma citação em blocoPode ter um cite com a fonte.
  • <code>
    mostra código no meio do textoCostuma ficar em fonte monoespaçada.
  • <pre>
    mantém os espaços e as quebras como foram escritosBom para blocos de código.

Links e mídia

Ligações, imagens, vídeo e áudio.

  • <a href="pagina.html">texto</a>
    um link para outra páginaO href é o destino. Para outro site use https://…
  • <a href="#secao">
    link para um lugar da mesma páginaA seção precisa de id="secao".
  • <a href="…" target="_blank" rel="noopener">

  • <audio controls src="som.mp3">
    um áudio com botões de controleFunciona como o vídeo.
  • <iframe src="…">
    uma página dentro da páginaMuitos sites bloqueiam ser abertos assim.

Atributos úteis

Ajustes que valem para quase qualquer tag.

  • id="nome"
    dá um nome único ao elementoO CSS usa #nome e o JavaScript, getElementById.
  • class="nome"
    dá um nome de grupo ao elementoVários elementos podem ter a mesma class.
  • style="color: red"
    aplica CSS direto na tagPrefira um arquivo de CSS.
  • title="dica"
    texto que aparece ao passar o mouseNão depende só dele para informar algo importante.
  • hidden
    esconde o elementoO JavaScript pode tirar o atributo para mostrar de novo.
  • data-algo="valor"
    guarda um dado personalizado na tagO JavaScript lê com elemento.dataset.algo.
  • tabindex="0"
    faz o elemento receber foco pelo teclado-1 permite focar por código, mas não pelo Tab.
  • aria-label="descrição"
    dá um nome a um elemento para leitores de telaÚtil em botões que só têm ícone.
