Antes de começar

O HTML em três ideias.

Ideia 1Tudo é etiqueta

Cada parte da página é uma tag: <h1> é um título, <p> um parágrafo, <img> uma imagem, <a> um link.

Ideia 2Abre e fecha

A maioria das tags abre e fecha: <h1>Título</h1>. Esquecer o fechamento é o erro número um.

Ideia 3Tags dentro de tags

Uma lista <ul> tem vários <li> dentro. É isso que dá estrutura à página.

Imagem é arquivoVem de uma pasta

O <img src="imagens/pao.png"> aponta para um arquivo na pasta imagens do projeto.

Bônus · como uma imagem é guardada

Uma imagem é uma grade de pixels.

As imagens dos ícones são arquivos PNG. Dentro, cada pixel (quadradinho) guarda uma cor, e o computador guarda tudo como bytes. Para ver isso de perto, aqui vai uma imagem minúscula de 8 por 8 pixels, em preto e branco: cada linha vira um número. Aperte nos quadrados.

Um PNG de verdade guarda 4 bytes por pixel (vermelho, verde, azul e transparência) e comprime o resultado. Uma foto de 1000 por 1000 pixels tem 1 milhão de pixels, ou 4 milhões de bytes antes de comprimir. Por isso fotos usam JPG, que aceita perder um pouco de qualidade para ficar leve, e logos simples usam SVG, que guarda a receita do desenho em vez dos pixels.

Comandos desta etapa.

Onde estou e o que tem aqui

  • pwdmostra em qual pasta você está
  • lslista os arquivos e pastas daqui (no Windows: dir)
  • cd pastaentra na pasta · cd .. volta uma · cd sozinho vai para a sua pasta pessoal

Criar

  • mkdir nomecria uma pasta (no Windows: md nome)
  • touch arquivocria um arquivo vazio (no Windows PowerShell: ni arquivo)
  • echo 'texto' > arquivoescreve o texto no arquivo, apagando o que havia
  • echo 'texto' >> arquivoacrescenta o texto no fim do arquivo

Ver

  • cat arquivomostra o conteúdo do arquivo (no Windows: type arquivo)
