Python escreve o site.

Um arquivo HTML é só texto. Se é texto, um programa pode escrevê-lo. Isso é o começo dos geradores de sites: você descreve os dados uma vez e o código monta as páginas.

Texto que vira página.

Tudo o que você escreveu à mão no nível 1 pode ser produzido por código, com a vantagem de poder repetir, variar e consertar de uma vez só.

Arquivosopen e write

Quando algo foge do esperado

Quando o programa funciona, mas a página sai errada.

Aqui o Python não dá erro e o resultado ainda assim pode estar errado: aprender a olhar o arquivo gerado é metade do trabalho.

O método de 5 passos

  1. Leia a mensagem inteira. Não pule: ela diz o tipo do erro, o arquivo e a linha. No Python, comece pela última linha.
  2. Vá até a linha indicada. Olhe a linha e a de cima: o erro real muitas vezes está um pouco antes.
  3. Reduza o problema. Comente ou apague o que não é necessário até o erro sumir. O último pedaço que você tirou era o culpado.
  4. Mostre os valores. Use print() no Python e console.log() no JavaScript para ver o que as variáveis guardam de verdade.
  5. Compare e só então pesquise. Compare com um exemplo que funciona. Se ainda travar, procure a mensagem de erro com o nome da linguagem.

  • FileNotFoundErrorO arquivo lido não existe nessa pasta. Conferir com ls e criar antes de ler.
  • Página em brancoO arquivo foi criado vazio ou com o nome diferente do que a minitela mostra. Troque a página no menu da minitela.
