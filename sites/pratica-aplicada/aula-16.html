1 · Como pensar

Um gerador, não um site.

Você não escreve o site: escreve o programa que escreve o site. Isso é o que permite criar variações em segundos.

CONFIGUm lugar para as escolhas

Cor, título e efeito ficam no topo, em um dicionário. O resto do programa só lê esses valores.

FunçõesCada parte no seu lugar

Uma função para o CSS, uma para o JavaScript e uma para cada página mantêm o programa legível.

Textos longosTrês aspas

""" … """ guarda um texto de várias linhas, ótimo para CSS e JavaScript.

VariarMudar e rodar de novo

O teste de verdade: troque a cor no CONFIG, rode outra vez e o site inteiro muda.

Quando algo foge do esperado

Aqui os erros se encontram.

Neste desafio vale tudo o que você viu: erros de Python, de HTML gerado, de CSS e de JavaScript. O painel mostra todos juntos.

O método de 5 passos

  1. Leia a mensagem inteira. Não pule: ela diz o tipo do erro, o arquivo e a linha. No Python, comece pela última linha.
  2. Vá até a linha indicada. Olhe a linha e a de cima: o erro real muitas vezes está um pouco antes.
  3. Reduza o problema. Comente ou apague o que não é necessário até o erro sumir. O último pedaço que você tirou era o culpado.
  4. Mostre os valores. Use print() no Python e console.log() no JavaScript para ver o que as variáveis guardam de verdade.
  5. Compare e só então pesquise. Compare com um exemplo que funciona. Se ainda travar, procure a mensagem de erro com o nome da linguagem.

Erros comuns desta aula

  • Chaves em f-stringCSS e JavaScript têm { }. Em f-strings, dobre {{ }} — ou escreva esses textos sem f e use .replace().
  • O erro está no arquivo gerado, não no PythonCorrija o programa que gera, rode de novo e olhe o resultado. Arrumar o arquivo gerado não adianta: ele será sobrescrito.
  • A cor não mudouO CSS tem a cor fixa no texto. Troque pelo valor de CONFIG["cor"].
  • Página sem estilo ou sem scriptFalta <link> ou <script> nas páginas geradas, ou o nome do arquivo difere.
  • Conferência diz que falta algoReleia o objetivo com calma: ele descreve o resultado esperado, não um jeito único de chegar lá.
