1 · Quatro ideias

O mínimo para começar.

Python é uma linguagem de leitura fácil, muito usada para automatizar tarefas, tratar dados e gerar arquivos.

printMostrar na tela

print("texto") escreve uma linha. É a sua lanterna: serve para ver o que o programa está fazendo.

VariáveisCaixas com nome

nome = "Pão" guarda o texto em uma caixa chamada nome. Depois você usa a caixa em vez de repetir o valor.

Listas e laçosMuitos itens, uma regra

Uma lista guarda vários valores; um laço for repete a mesma ação para cada um.

FunçõesReceitas com nome

def frase(item): return ... cria um bloco reutilizável. O recuo (4 espaços) mostra o que pertence a ele.

Quando algo foge do esperado

Python diz o que deu errado.

Os erros do Python são longos, mas honestos. Aqui você vai errar de propósito e aprender a ler cada um.

O método de 5 passos

  1. Leia a mensagem inteira. Não pule: ela diz o tipo do erro, o arquivo e a linha. No Python, comece pela última linha.
  2. Vá até a linha indicada. Olhe a linha e a de cima: o erro real muitas vezes está um pouco antes.
  3. Reduza o problema. Comente ou apague o que não é necessário até o erro sumir. O último pedaço que você tirou era o culpado.
  4. Mostre os valores. Use print() no Python e console.log() no JavaScript para ver o que as variáveis guardam de verdade.
  5. Compare e só então pesquise. Compare com um exemplo que funciona. Se ainda travar, procure a mensagem de erro com o nome da linguagem.

Erros comuns desta aula

  • SyntaxErrorA linha está escrita de um jeito que o Python não entende: dois pontos, aspas ou parênteses faltando.
  • IndentationErrorO recuo está errado. Dentro de for, if e def, as linhas precisam ficar mais para dentro.
  • NameErrorVocê usou um nome que ainda não existe (ou escreveu diferente: maiúsculas contam).
  • TypeErrorMisturou tipos, como "texto" + 3. Converta com str() ou int().
  • python: can't open fileO arquivo não está na pasta onde você está. Use ls e confira o nome.
