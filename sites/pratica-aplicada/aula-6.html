CSS responsivo.

Muita gente vai abrir o seu site pelo celular. Um site responsivo se adapta à tela de quem olha: o mesmo HTML, o mesmo CSS, três jeitos de se organizar. Aqui você vê a ideia funcionando e aplica ao site da sua prática.

1 · As quatro ideias

Como um site se adapta.

Ideia 1Avisar o aparelho

A tag meta viewport diz ao celular para usar a largura real da tela.

Ideia 2Medidas que se ajustam

Em vez de pixels fixos, use %, rem e clamp(): o tamanho acompanha a tela.

Ideia 3Layout que se reorganiza

Com @media, 3 colunas viram 2 e depois 1; o menu lateral vai para o topo.

Ideia 4Pensar em quem usa

Alvos de toque grandes, tema escuro do aparelho e respeito a quem pede menos movimento.

2 · Simulador de largura

Arraste e veja o layout mudar.

A página abaixo tem duas regras @media. Arraste a largura (ou use os botões) e veja em qual ponto de quebra ela muda.

página de exemplo
1200 px
@media (max-width: 900px) { .g { grid-template-columns: repeat(2, 1fr); } }
@media (max-width: 560px) { .g { grid-template-columns: 1fr; } }

Comandos de CSS responsivo

  • <meta name="viewport" ...>avisa o celular para usar a largura real da tela
  • max-width: 100%imagem que nunca passa do espaço disponível
  • clamp(1.8rem, 5vw, 2.8rem)tamanho que cresce com a tela entre um mínimo e um máximo
  • @media (max-width: 600px)regras que só valem em telas de até 600 px
  • grid-template-columns: repeat(auto-fit, minmax(200px, 1fr))colunas que se ajustam sozinhas, sem @media
  • flex-wrap: wrapitens quebram de linha quando falta espaço
  • @media (prefers-color-scheme: dark)acompanha o tema escuro do aparelho
  • @media (prefers-reduced-motion: reduce)desliga animações para quem pediu menos movimento
