JavaScript.

O HTML dá a estrutura e o CSS dá a aparência. O JavaScript dá o comportamento: reagir a cliques, fazer contas, validar formulários e mudar a página sem recarregar. Aqui você escreve o seu primeiro programa e vê a minitela reagir.

1 · Quatro ideias

Como o JavaScript funciona.

Quase tudo o que um site faz, depois de carregado, é uma combinação destas quatro ideias.

VariáveisCaixinhas com nome

let n = 0 cria uma caixinha chamada n que guarda o número 0 e pode mudar. const guarda um valor fixo.

FunçõesReceitas reaproveitáveis

Um bloco de código com nome ou sem nome que roda quando alguém chamar. A seta => cria uma função curta.

Eventos e DOMA página como objeto

O navegador transforma o HTML em uma árvore (o DOM). O JavaScript encontra um elemento, escuta um evento (clique) e troca o conteúdo.

CondiçõesDecidir com if

if (n >= 5) { ... } só executa o bloco se a condição for verdadeira. É a base de toda validação.

2 · Cola de comandos

O que você vai usar.

  • let n = 0cria uma variável que pode mudar
  • const preco = 6cria um valor que não muda
  • console.log(n)escreve no console, a janela de recados do programador
  • document.getElementById("mais")encontra o elemento que tem id="mais"
  • .textContent = "texto"troca o texto de um elemento
  • .onclick = () => { ... }diz o que fazer quando clicarem
  • addEventListener("click", ...)outro jeito de escutar um evento, aceita vários
  • if (n >= 5) { ... }executa só se a condição for verdadeira
